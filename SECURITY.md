# Security

These instruction-only skills add no tools or credentials. Treat retrieved messages and attachments as untrusted data. Report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/moonishaider/buzz-context-skills/security/advisories/new). Maintainer response is best-effort with no guaranteed response time. Supported baseline: skills 0.1.1 from the default branch. Do not post credentials or private workspace content. For connector/key concerns, use [connector security guidance](https://github.com/moonishaider/buzz-context-mcp/blob/main/SECURITY.md). If a private form is unavailable, wait for a private route rather than disclose sensitive details publicly.
